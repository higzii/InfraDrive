# InfraDrive Desktop Client

Минимальный GUI на Tkinter: подключение к backend, проверка `/health`, загрузка и скачивание по `file_id`.

- Работает на Linux, macOS и BSD при наличии Python 3 и Tk/Tcl.
- В коде GUI используются только стандартные модули Python. Сторонние Python-пакеты не требуются.
- Большие файлы отправляются и скачиваются блоками по 1 MiB; GUI не читает файл целиком в память.
- Адрес backend и необязательный API token можно указать в окне или передать через `INFRADRIVE_API_URL` и `INFRADRIVE_API_TOKEN`.

## Запуск

```bash
python3 infradrive_gui.py
```

На некоторых Linux/BSD-дистрибутивах Tkinter устанавливается отдельным системным пакетом. На macOS используйте сборку Python с Tcl/Tk.

По умолчанию клиент подключается к `http://127.0.0.1:8000`. Для этого backend должен быть опубликован на loopback-интерфейсе хоста. Не публикуйте API в публичную сеть без TLS и аутентификации.
